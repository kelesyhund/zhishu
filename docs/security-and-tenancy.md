# 安全与租户隔离

## 安全模型

知枢默认不信任客户端传入的组织、工作空间、知识库、会话、文档或模型配置 ID。所有嵌套资源先限定到当前身份可访问的父资源，再查询子资源；不存在、越权和父子关系不匹配统一按资源不可见处理。

## 身份与权限

- 浏览器后台使用 HttpOnly Session Cookie 与 CSRF 防护。
- 组织和工作空间成员关系决定资源可见范围。
- 固定角色与权限码控制管理、编辑、使用和只读操作。
- 公开应用使用独立的发布凭证，不复用后台 Session。
- 服务端是权限判断的唯一可信来源，前端按钮隐藏仅用于交互提示。

关键写操作需要同时验证：操作者身份、组织成员状态、工作空间角色、资源归属和目标对象状态。权限变更与敏感管理操作写入审计日志。

## 密钥与令牌

- 模型 API Key 使用 Fernet 对称加密后存库；加密主密钥仅由运行环境提供。
- 查询接口只返回是否已配置及末尾字符的脱敏表示，不返回明文或密文。
- 应用 API Key、邀请令牌和重置令牌只保存不可逆摘要。
- API Key 更新采用“缺省为保留、非空新值为轮换”的语义，脱敏占位符不能作为新密钥保存。
- `.env`、数据库、备份、上传文件和模型权重均被排除在版本控制之外。

加密主密钥丢失后，数据库中的模型密钥无法恢复；生产环境必须把该密钥纳入受控的密钥托管与备份流程。

## 外部模型端点

模型 Base URL 在保存和调用前都会校验：

- 仅允许 HTTP/HTTPS，生产环境默认要求 HTTPS。
- 拒绝 URL 用户信息、查询参数、片段和异常格式。
- 默认拒绝环回、私有、链路本地、保留地址及云元数据地址。
- DNS 解析后的全部地址再次检查，调用前重新验证以降低 DNS 重绑定风险。
- 客户端设置明确超时，不跟随不受控的跨域重定向。

本地模型访问只能通过显式开发配置开启，不应复用于互联网生产环境。

## 数据与日志

- 日志使用结构化字段和请求关联 ID，不记录 Authorization、Cookie、原始密钥或文档正文。
- 外部 SDK 异常映射为稳定的用户消息；内部地址和原始请求对象不返回前端。
- 测试使用临时数据库、临时 MEDIA_ROOT 和假密钥，禁止触达真实外部模型。
- 导出、备份和恢复继承与在线系统相同的数据分级要求。

## 主要威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 伪造资源 ID 越权 | 父资源作用域查询、owner/organization/workspace 联合校验 |
| API Key 泄漏 | 加密存储、脱敏响应、日志过滤、前端不持久化 |
| SSRF | URL 规范化、IP/DNS 校验、协议限制、调用前复验 |
| 重放或重复写入 | CSRF、幂等键、任务锁、数据库唯一约束 |
| 异步删除竞态 | 任务状态机、资源存在性复验、清理服务与事务 |
| 不兼容向量混用 | EmbeddingSpace、revision/signature 校验、检索过滤 |
| 公开接口滥用 | 独立凭证、限流、最小发布快照、审计指标 |

漏洞报告流程见仓库根目录 [SECURITY.md](../SECURITY.md)。
